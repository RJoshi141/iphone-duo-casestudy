# Third-party assets

The interactive phone component (`src/iphone-duo/`) is adapted from an MIT-licensed
open-source demo (https://github.com — see LICENSE for the original terms). The code
in that folder, and the code in the rest of this project, is MIT licensed by me.

The following are **not** covered by that license:

- `public/models/iphone-duo.glb` — Apple's 3D model of iPhone Duo, from Apple's iPhone
  Duo product page. Used here for a non-commercial, independent product study, with
  attribution. This project is not affiliated with or endorsed by Apple.
- `public/wallpapers/apple-desert-day.avif`, `apple-desert-day-cover.avif`,
  `apple-desert-night.avif`, `apple-desert-night-cover.avif` — day/night desert
  wallpaper images, not made by me. Used here for the phone's screen texture only.

`public/wallpapers/home-apps.svg` and `home-cover.svg` are original SVG artwork I
made for this project (a generic home-screen recreation with an original icon set),
covered by the MIT license above, except for the time/wifi status cluster in the
top-right corner, which is adapted from Apple's iOS 27 / iPadOS UI kit (Figma), used
here under the same independent-study terms as the rest of Apple's assets.
